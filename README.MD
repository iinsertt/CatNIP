# CatNIP

CatNIP — это минималистичный сетевой протокол с минимальной реализацией собственного шифрования.

Данный проект **НЕ** готов для релиза и не может быть использован в текущем состоянии в реальных проектах.

## 🔒 Описание шифрования

В данном проекте реализовано шифрование при помощи синхронно генерирующейся матрицы.

К примеру: сервер и клиент подключились друг к другу, обменялись ключами и начинают обмен пакетами.

При передаче пакетов не будет отправляться стандартный набор зашифрованных байтов.
Точнее, байты будут, но они — лишь результат наложения синхронной маски на открытые данные.
Можно представить это как "указатели" на байты матрицы, применяемые по позиции:

<pre> 
Входная информация: "hello"
Котировка в байтах:   { 0x68, 0x65, 0x6C, 0x6C, 0x6F }

↓ ↓ ↓

[0x68 ⊕ 0x12 @ (12)][0x65 ⊕ 0x1F @ (13)][0x6C ⊕ 0x2A @ (14)]...
         ↑                   ↑                   ↑
         |                   |                   |
     MATRIX BYTE         MATRIX BYTE         MATRIX BYTE
     POSITION 12         POSITION 13         POSITION 14
</pre>

| Input Byte (`"hello"`) | Matrix Byte | XOR Result (Encrypted Byte)   |
|:----------------------:|:-----------:|:-----------------------------:|
|         `0x68`         |   `0x12`    |            `0x7A`             |
|         `0x65`         |   `0x1F`    |            `0x7A`             |
|         `0x6C`         |   `0x2A`    |            `0x46`             |
|         `0x6C`         |   `0x03`    |            `0x6F`             |
|         `0x6F`         |   `0x10`    |            `0x7F`             |

> После шифрования формируется HMAC-SHA256 (32 байта),  
> который подписывает итоговые зашифрованные байты с использованием общего `key`.  
> Это обеспечивает защиту от подделки и проверку целостности данных.
